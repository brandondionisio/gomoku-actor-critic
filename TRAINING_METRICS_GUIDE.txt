================================================================================
GOMOKU RL TRAINING METRICS GUIDE
================================================================================

This guide explains what metrics to monitor during training and what values
indicate good vs poor performance.

================================================================================
PERFORMANCE METRICS
================================================================================

1. WIN RATE
   Description: Percentage of games won by the agent
   
   Self-Play Training:
   - OPTIMAL: 45-55% (both sides improving equally)
   - WARNING: < 40% or > 60% (imbalance, one side too strong/weak)
   - POOR: < 30% or > 70% (severe imbalance)
   
   Random Opponent Training:
   - OPTIMAL: > 80% (agent should beat random consistently)
   - WARNING: 60-80% (learning but not strong)
   - POOR: < 60% (not learning effectively)

2. AVERAGE REWARD
   Description: Cumulative average reward per episode
   
   Self-Play Training:
   - OPTIMAL: Increasing over time, typically 0.2-0.5
   - WARNING: Stable but low (< 0.1) or decreasing
   - POOR: Negative or rapidly decreasing
   
   Random Opponent Training:
   - OPTIMAL: > 0.5 and increasing
   - WARNING: 0.2-0.5 and stable
   - POOR: < 0.2 or decreasing

3. ROLLING AVERAGE REWARD (Last 100 Episodes)
   Description: Smoothed reward trend, reduces noise
   
   - OPTIMAL: Gradually increasing trend
   - WARNING: Flat or slightly decreasing
   - POOR: Rapidly decreasing or highly volatile

4. EPISODE LENGTH
   Description: Average number of moves per game
   
   - OPTIMAL: Decreasing over time (stronger play = faster wins)
   - WARNING: Stable or slowly increasing
   - POOR: Rapidly increasing (games dragging on, poor play)

================================================================================
TRAINING HEALTH METRICS
================================================================================

5. ADVANTAGES (Mean ± Std)
   Description: How much better/worse actions are than expected
   
   - OPTIMAL: Mean near 0.0, Std < 0.5 (stable learning)
   - WARNING: Mean far from 0 (> 1.0 or < -1.0) or Std > 1.0
   - POOR: Mean > 2.0 or < -2.0, Std > 2.0 (unstable)

6. TOTAL LOSS
   Description: Combined policy + value + entropy loss
   
   - OPTIMAL: Decreasing or stable at low value (< 1.0)
   - WARNING: Increasing or stable at high value (1.0-2.0)
   - POOR: > 2.0 or rapidly increasing

7. POLICY LOSS
   Description: How well the policy is learning
   
   - OPTIMAL: Decreasing over time, typically < 0.5
   - WARNING: Stable at 0.5-1.0 or slowly increasing
   - POOR: > 1.0 or rapidly increasing

8. VALUE LOSS
   Description: How well the value function estimates rewards
   
   - OPTIMAL: < 0.5 and decreasing (value function learning well)
   - WARNING: 0.5-1.0 and stable (value function struggling)
   - POOR: > 1.0 or rapidly increasing (value function unstable)
   
   NOTE: Value loss > 1.0 is a CRITICAL WARNING - indicates training instability

9. ENTROPY
   Description: Exploration vs exploitation balance
   
   - OPTIMAL: 0.5-2.0 (good exploration, learning diverse strategies)
   - WARNING: 0.1-0.5 (exploration decreasing, may get stuck)
   - POOR: < 0.1 (exploration collapsed, model too deterministic)
   
   NOTE: Entropy < 0.1 means the model has stopped exploring - this is BAD

================================================================================
CRITICAL WARNING SIGNS
================================================================================

🚨 IMMEDIATE ACTION REQUIRED IF YOU SEE:

1. Value Loss > 1.0
   - Problem: Value function is unstable
   - Fix: Reduce learning rate, increase value_coef, or check for bugs

2. Entropy < 0.1
   - Problem: Model stopped exploring
   - Fix: Increase entropy_coef, reduce learning rate

3. Average Reward Rapidly Decreasing
   - Problem: Model is getting worse (catastrophic forgetting)
   - Fix: Reduce learning rate, increase opponent update interval

4. Advantages with High Std (> 2.0)
   - Problem: Training is unstable
   - Fix: Reduce learning rate, check reward scaling

5. Win Rate < 20% or > 80% in Self-Play
   - Problem: Severe imbalance between agent and opponent
   - Fix: Adjust opponent update interval, check if opponent is too weak/strong

================================================================================
INTERPRETING METRICS TOGETHER
================================================================================

GOOD TRAINING SIGNALS:
✓ Rolling average reward gradually increasing
✓ Value loss < 0.5 and stable
✓ Entropy > 0.5 (good exploration)
✓ Advantages near 0 with low std
✓ Episode length decreasing
✓ Win rate 45-55% in self-play (or > 80% vs random)

POOR TRAINING SIGNALS:
✗ Average reward decreasing
✗ Value loss > 1.0
✗ Entropy < 0.1
✗ Advantages with high std (> 1.0)
✗ Episode length increasing
✗ Win rate extreme (< 30% or > 70% in self-play)

PLATEAU DETECTION:
- Rolling average reward stable for 200+ episodes
- Losses stable but not decreasing
- Win rate stable at suboptimal level
- Consider: Learning rate decay, more exploration, or different hyperparameters

================================================================================
QUICK DIAGNOSTIC CHECKLIST
================================================================================

Before worrying about performance, check:

□ Value Loss < 1.0? (If NO → CRITICAL: Fix value function)
□ Entropy > 0.1? (If NO → CRITICAL: Increase exploration)
□ Advantages std < 1.0? (If NO → Training unstable)
□ Rolling average reward stable or increasing? (If NO → Model degrading)
□ Episode length reasonable? (If NO → Games too long/short)

If all above are YES, then training is healthy. Focus on:
- Is reward increasing? (If not, may need more training or hyperparameter tuning)
- Is win rate appropriate? (Self-play: 45-55%, Random: > 80%)

================================================================================
EXPECTED TRAINING PROGRESSION
================================================================================

Early Training (Episodes 0-500):
- High entropy (> 1.0) - exploring
- High losses (> 1.0) - learning
- Variable rewards - still learning
- Win rate may be unstable

Mid Training (Episodes 500-2000):
- Entropy decreasing (0.5-1.0) - more focused
- Losses decreasing (< 1.0) - learning
- Rewards increasing - improving
- Win rate stabilizing

Late Training (Episodes 2000+):
- Entropy stable (0.3-0.8) - balanced exploration
- Losses low and stable (< 0.5) - converged
- Rewards stable or slowly increasing
- Win rate stable (self-play: 45-55%)

================================================================================
NOTES
================================================================================

- Metrics should be interpreted together, not in isolation
- Short-term fluctuations are normal - focus on trends over 50-100 episodes
- Self-play metrics differ from random opponent metrics
- If training seems stuck, try different hyperparameters or more training time
- Save checkpoints regularly to compare model performance
